# 3D Studio（3d）操作清单

分组：creative · 替代 Autodesk Maya, SketchUp · 许可证 AGPL-3.0-only · 页面标题「3D · Scene editor」

共 230 个操作，全部有语义命令（`foxos 3d <资源> <动词>`，MCP 工具 `3d.<资源>.<动词>`）。绑定方式为 ui：命令在应用的真实界面上执行与人相同的点击 / 输入 / 按键，界面实时更新。

由 `python scripts/inventory_ops.py` 从运行中的应用生成，不要手工编辑。
