# Building Design（building-design）操作清单

分组：engineering · 替代 Autodesk Revit, ArchiCAD, Vectorworks · 许可证 AGPL-3.0-only · 页面标题「Building Design」

共 1 个操作，全部有语义命令（`foxos building-design <资源> <动词>`，MCP 工具 `building-design.<资源>.<动词>`）。绑定方式为 ui：命令在应用的真实界面上执行与人相同的点击 / 输入 / 按键，界面实时更新。

由 `python scripts/inventory_ops.py` 从运行中的应用生成，不要手工编辑。

| 操作 ID | CLI | 界面路径 / 快捷键 | 参数 | 效果 | 可撤销（推断） |
|---|---|---|---|---|---|
| `it.dismiss` | `foxos building-design it dismiss` | 主界面 > Early alpha notice > Got it | — | 点击「Got it」（button） | 不适用（只读） |
